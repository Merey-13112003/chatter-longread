# Let's Talk: How Adults Learn to Make Friends

Многостраничный лонгрид: 9 страниц, общий стиль и навигация.

## Как открыть
Откройте папку в VS Code → правой кнопкой по `index.html` → **Open with Live Server**
(расширение «Live Server»). Если открыть файл просто двойным кликом, видео с YouTube
может не загрузиться: YouTube требует, чтобы страница открывалась через сервер.

## Ваш текст
Всё, что ещё нужно написать, стоит в [квадратных скобках] и выделено серым курсивом
с пунктиром слева. Замените текст и удалите `placeholder` из `class="..."`.

## Аудио Нейлы и Дидара
Они играют прямо из Google Drive. В Drive должен стоять доступ
**«Все, у кого есть ссылка»**, иначе плеер не откроется.

## Аудио Надии с субтитрами
Субтитры не могут синхронизироваться с плеером Google Drive, поэтому:
1. Скачайте запись Надии из Drive и сохраните её как `assets/audio/nadiya.mp3`.
2. Откройте `tools/subtitle-maker.html` в браузере.
3. Выберите файл, вставьте текст её речи (одна строка = один субтитр).
4. Нажмите «Начать» и жмите Пробел каждый раз, когда начинается новая строка.
5. Скопируйте результат и вставьте его в `js/nadiya-subtitles.js`.

Если Надия говорит по-русски, вставляйте английский перевод: субтитры будут на английском.

## Добавить или убрать страницу
Список страниц и их порядок задаётся в начале `js/main.js` (массив `PAGES`).
У каждой страницы в `<body data-page="N">` стоит её номер, начиная с 0.
